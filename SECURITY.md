# Security Policy

## Supported versions

Security fixes are made for the latest published release. Update to the latest release before reporting an issue; older releases are not guaranteed to receive fixes.

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues or pull requests. Use [GitHub's private vulnerability reporting form](https://github.com/Rhyru9/bug-solver-pro/security/advisories/new). If private reporting is unavailable, contact the project owner privately through [GitHub](https://github.com/Rhyru9).

Include the affected version or commit, the relevant files or feature, steps to reproduce, and the impact you observed. You may attach a minimal proof of concept, but do not include real credentials, personal data, or other sensitive information.

The maintainers will review the report and coordinate any fix and disclosure with the reporter. Response and resolution times depend on the report and maintainer availability; please avoid disclosing the issue publicly until a fix or coordinated disclosure is agreed.
